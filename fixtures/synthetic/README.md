# Synthetic fixtures

Only synthetic or independently redistributable fixtures may be committed here.

Do not use private Asher Tech game art, client work, credentials, or personal files.

Fixture groups should eventually cover:

- clean static PNGs;
- one-byte mutations;
- corrupt/truncated PNGs;
- oversized dimensions;
- pathological metadata;
- Unicode/spaces/case-collision filenames;
- symlink/traversal test structures generated during tests where possible.
